# Volume 3, Part 1: E-Commerce & Retail Scenarios (Questions 1-100)

**Domain Context:** You are the Lead Data Engineer for an international e-commerce retailer. 
**Core Schema:**
*   `Customers` (CustomerID, FirstName, LastName, Email, SignupDate, Country)
*   `Orders` (OrderID, CustomerID, OrderDate, TotalAmount, Status)
*   `OrderItems` (OrderItemID, OrderID, ProductID, Quantity, UnitPrice)
*   `Products` (ProductID, CategoryID, ProductName, StockQuantity, IsActive)
*   `Categories` (CategoryID, CategoryName)

---

## Section 1: Basic Reporting (Questions 1-20)

**Q1: The CEO wants a list of all active products.**
*   **Solution:** `SELECT ProductName FROM Products WHERE IsActive = 1;` (Use `TRUE` for Postgres).

**Q2: Find the total number of customers from Canada.**
*   **Solution:** `SELECT COUNT(*) FROM Customers WHERE Country = 'Canada';`

**Q3: Calculate the total revenue generated across all time.**
*   **Solution:** `SELECT SUM(TotalAmount) FROM Orders WHERE Status = 'Completed';`

**Q4: Find the average order value (AOV) for the year 2025.**
*   **Solution:** `SELECT AVG(TotalAmount) FROM Orders WHERE OrderDate >= '2025-01-01' AND OrderDate < '2026-01-01';`

**Q5: List the top 5 most expensive products currently in stock.**
*   **Solution (SQL Server):** `SELECT TOP 5 ProductName, UnitPrice FROM Products WHERE StockQuantity > 0 ORDER BY UnitPrice DESC;`
*   **Solution (Postgres):** `SELECT ProductName, UnitPrice FROM Products WHERE StockQuantity > 0 ORDER BY UnitPrice DESC LIMIT 5;`

**Q6: Identify any customers who signed up but haven't provided a last name.**
*   **Solution:** `SELECT CustomerID, Email FROM Customers WHERE LastName IS NULL OR TRIM(LastName) = '';`

**Q7: The marketing team needs a list of unique countries where our customers live.**
*   **Solution:** `SELECT DISTINCT Country FROM Customers;`

**Q8: Find all orders placed between Black Friday and Cyber Monday (Nov 28, 2025 - Dec 1, 2025).**
*   **Solution:** `SELECT OrderID FROM Orders WHERE OrderDate BETWEEN '2025-11-28' AND '2025-12-01 23:59:59';`

**Q9: Count how many orders each customer has placed.**
*   **Solution:** `SELECT CustomerID, COUNT(OrderID) AS OrderCount FROM Orders GROUP BY CustomerID;`

**Q10: Find customers who have placed more than 10 orders.**
*   **Solution:** `SELECT CustomerID, COUNT(OrderID) FROM Orders GROUP BY CustomerID HAVING COUNT(OrderID) > 10;`

**Q11: Show the CategoryName alongside each ProductName.**
*   **Solution:** `SELECT p.ProductName, c.CategoryName FROM Products p INNER JOIN Categories c ON p.CategoryID = c.CategoryID;`

**Q12: List all customers and their orders. Include customers who have never placed an order.**
*   **Solution:** `SELECT c.Email, o.OrderID FROM Customers c LEFT JOIN Orders o ON c.CustomerID = o.CustomerID;`

**Q13: Find the total revenue generated by each Category.**
*   **Solution:** `SELECT c.CategoryName, SUM(oi.Quantity * oi.UnitPrice) AS Revenue FROM Categories c INNER JOIN Products p ON c.CategoryID = p.CategoryID INNER JOIN OrderItems oi ON p.ProductID = oi.ProductID GROUP BY c.CategoryName;`

**Q14: Identify products that have never been sold.**
*   **Solution:** `SELECT p.ProductName FROM Products p LEFT JOIN OrderItems oi ON p.ProductID = oi.ProductID WHERE oi.OrderItemID IS NULL;`

**Q15: Find the most popular product by total quantity sold.**
*   **Solution (SQL Server):** `SELECT TOP 1 ProductID, SUM(Quantity) AS TotalSold FROM OrderItems GROUP BY ProductID ORDER BY TotalSold DESC;`

**Q16: Calculate the total number of items in Order #1005.**
*   **Solution:** `SELECT SUM(Quantity) FROM OrderItems WHERE OrderID = 1005;`

**Q17: Find customers whose email addresses end with '@gmail.com'.**
*   **Solution:** `SELECT CustomerID FROM Customers WHERE Email LIKE '%@gmail.com';`

**Q18: Sort customers by Country alphabetically, and then by SignupDate newest to oldest.**
*   **Solution:** `SELECT * FROM Customers ORDER BY Country ASC, SignupDate DESC;`

**Q19: Generate a single string formatting the customer's location as "Country: [Country]".**
*   **Solution (SQL Server):** `SELECT CONCAT('Country: ', Country) FROM Customers;`

**Q20: Find the largest single order amount ever processed.**
*   **Solution:** `SELECT MAX(TotalAmount) FROM Orders;`

## Section 2: Customer Retention and Cohorts (Questions 21-40)

**Q21: Find the date of the very first order placed by each customer.**
*   **Solution:** `SELECT CustomerID, MIN(OrderDate) AS FirstOrderDate FROM Orders GROUP BY CustomerID;`

**Q22: Count how many new customers signed up in each month of 2025.**
*   **Solution (SQL Server):** `SELECT MONTH(SignupDate) AS SignupMonth, COUNT(*) FROM Customers WHERE YEAR(SignupDate) = 2025 GROUP BY MONTH(SignupDate);`

**Q23: Identify "One-and-Done" customers (those who have exactly 1 completed order).**
*   **Solution:** `SELECT CustomerID FROM Orders WHERE Status = 'Completed' GROUP BY CustomerID HAVING COUNT(OrderID) = 1;`

**Q24: Find customers who signed up in 2024 but didn't place their first order until 2025.**
*   **Solution:** `SELECT c.CustomerID FROM Customers c INNER JOIN Orders o ON c.CustomerID = o.CustomerID WHERE c.SignupDate < '2025-01-01' GROUP BY c.CustomerID HAVING MIN(o.OrderDate) >= '2025-01-01';`

**Q25: Calculate the average time (in days) between a customer signing up and placing their first order.**
*   **Solution (SQL Server):** 
    ```sql
    WITH FirstOrders AS (
        SELECT CustomerID, MIN(OrderDate) AS FirstOrder FROM Orders GROUP BY CustomerID
    )
    SELECT AVG(DATEDIFF(DAY, c.SignupDate, fo.FirstOrder)) 
    FROM Customers c INNER JOIN FirstOrders fo ON c.CustomerID = fo.CustomerID;
    ```

**Q26: Find the top 3 countries with the highest average order value.**
*   **Solution (Postgres):** `SELECT c.Country, AVG(o.TotalAmount) FROM Customers c INNER JOIN Orders o ON c.CustomerID = o.CustomerID GROUP BY c.Country ORDER BY AVG(o.TotalAmount) DESC LIMIT 3;`

**Q27: Identify "Whales" (Customers whose lifetime spending exceeds $10,000).**
*   **Solution:** `SELECT CustomerID, SUM(TotalAmount) FROM Orders GROUP BY CustomerID HAVING SUM(TotalAmount) > 10000;`

**Q28: Which customer has the highest number of cancelled orders?**
*   **Solution (SQL Server):** `SELECT TOP 1 CustomerID, COUNT(OrderID) FROM Orders WHERE Status = 'Cancelled' GROUP BY CustomerID ORDER BY COUNT(OrderID) DESC;`

**Q29: Find users who bought a product from the 'Electronics' category AND the 'Apparel' category.**
*   **Solution (Using INTERSECT):** 
    ```sql
    SELECT o.CustomerID FROM Orders o JOIN OrderItems oi ON o.OrderID = oi.OrderID JOIN Products p ON oi.ProductID = p.ProductID JOIN Categories c ON p.CategoryID = c.CategoryID WHERE c.CategoryName = 'Electronics'
    INTERSECT
    SELECT o.CustomerID FROM Orders o JOIN OrderItems oi ON o.OrderID = oi.OrderID JOIN Products p ON oi.ProductID = p.ProductID JOIN Categories c ON p.CategoryID = c.CategoryID WHERE c.CategoryName = 'Apparel';
    ```

**Q30: Calculate the percentage of orders that are 'Returned'.**
*   **Solution:** `SELECT (CAST(SUM(CASE WHEN Status = 'Returned' THEN 1 ELSE 0 END) AS FLOAT) / COUNT(*)) * 100 AS ReturnRate FROM Orders;`

**Q31: Create a monthly cohort showing total revenue grouped by the Customer's Signup Month.**
*   **Solution (SQL Server):** `SELECT FORMAT(c.SignupDate, 'yyyy-MM'), SUM(o.TotalAmount) FROM Customers c JOIN Orders o ON c.CustomerID = o.CustomerID GROUP BY FORMAT(c.SignupDate, 'yyyy-MM');`

**Q32: Find the last time each customer placed an order.**
*   **Solution:** `SELECT CustomerID, MAX(OrderDate) AS LastOrderDate FROM Orders GROUP BY CustomerID;`

**Q33: Identify "Churned" customers (those who haven't ordered in the last 12 months).**
*   **Solution (SQL Server):** `SELECT CustomerID FROM Orders GROUP BY CustomerID HAVING MAX(OrderDate) < DATEADD(MONTH, -12, GETDATE());`

**Q34: Find the most frequent day of the week that orders are placed.**
*   **Solution (SQL Server):** `SELECT TOP 1 DATENAME(WEEKDAY, OrderDate) AS OrderDay, COUNT(*) FROM Orders GROUP BY DATENAME(WEEKDAY, OrderDate) ORDER BY COUNT(*) DESC;`

**Q35: For each customer, list their most commonly purchased Category.**
*   **Solution (Using CTE & ROW_NUMBER):**
    ```sql
    WITH CatCounts AS (
        SELECT o.CustomerID, c.CategoryName, COUNT(*) as CatCount,
        ROW_NUMBER() OVER(PARTITION BY o.CustomerID ORDER BY COUNT(*) DESC) as rn
        FROM Orders o JOIN OrderItems oi ON o.OrderID = oi.OrderID JOIN Products p ON oi.ProductID = p.ProductID JOIN Categories c ON p.CategoryID = c.CategoryID
        GROUP BY o.CustomerID, c.CategoryName
    )
    SELECT CustomerID, CategoryName FROM CatCounts WHERE rn = 1;
    ```

## Section 3: Inventory and Supply Chain (Questions 41-60)

**Q41: Find all products where the `StockQuantity` has fallen below 10.**
*   **Solution:** `SELECT ProductID, ProductName FROM Products WHERE StockQuantity < 10;`

**Q42: Calculate the total potential revenue sitting in the warehouse (Stock * UnitPrice).**
*   **Solution:** `SELECT SUM(StockQuantity * UnitPrice) AS TotalInventoryValue FROM Products;`

**Q43: We want to discontinue a Category. Which category has generated the least revenue in the last 6 months?**
*   **Solution:** *(Requires joining Categories -> Products -> OrderItems -> Orders, filtering by Date, grouping by Category, ordering ASC, limit 1).*

**Q44: Find the product that is returned most frequently.**
*   **Solution:** `SELECT TOP 1 p.ProductName FROM Products p JOIN OrderItems oi ON p.ProductID = oi.ProductID JOIN Orders o ON oi.OrderID = o.OrderID WHERE o.Status = 'Returned' GROUP BY p.ProductName ORDER BY COUNT(*) DESC;`

**Q45: Identify orders where the `TotalAmount` in the `Orders` table does NOT match the sum of `(Quantity * UnitPrice)` in the `OrderItems` table (Data Anomaly Check).**
*   **Solution:**
    ```sql
    SELECT o.OrderID, o.TotalAmount, SUM(oi.Quantity * oi.UnitPrice) AS CalculatedTotal
    FROM Orders o
    JOIN OrderItems oi ON o.OrderID = oi.OrderID
    GROUP BY o.OrderID, o.TotalAmount
    HAVING o.TotalAmount <> SUM(oi.Quantity * oi.UnitPrice);
    ```

**Q46: Find products that have a stock of 0, but are still marked as `IsActive = 1`.**
*   **Solution:** `SELECT ProductID FROM Products WHERE StockQuantity = 0 AND IsActive = 1;`

## Section 4: Advanced Window Functions & YoY Growth (Questions 61-80)

**Q61: Calculate the Running Total of Revenue for the year 2025, ordered by date.**
*   **Solution:** 
    ```sql
    SELECT OrderDate, TotalAmount, 
    SUM(TotalAmount) OVER(ORDER BY OrderDate ASC) AS RunningTotal 
    FROM Orders WHERE YEAR(OrderDate) = 2025;
    ```

**Q62: Compare each order's amount to the average order amount in the same country.**
*   **Solution:**
    ```sql
    SELECT o.OrderID, c.Country, o.TotalAmount,
    AVG(o.TotalAmount) OVER(PARTITION BY c.Country) AS CountryAvg
    FROM Orders o JOIN Customers c ON o.CustomerID = c.CustomerID;
    ```

**Q63: Find the Month-Over-Month (MoM) revenue growth percentage.**
*   **Solution (Requires LAG):**
    ```sql
    WITH MonthlyRev AS (
        SELECT MONTH(OrderDate) as Mth, SUM(TotalAmount) as Rev FROM Orders WHERE YEAR(OrderDate)=2025 GROUP BY MONTH(OrderDate)
    )
    SELECT Mth, Rev, LAG(Rev, 1) OVER(ORDER BY Mth) AS PrevRev,
    ((Rev - LAG(Rev, 1) OVER(ORDER BY Mth)) / LAG(Rev, 1) OVER(ORDER BY Mth)) * 100 AS GrowthPct
    FROM MonthlyRev;
    ```

**Q64: Rank customers by their total lifetime spending using DENSE_RANK.**
*   **Solution:**
    ```sql
    SELECT CustomerID, SUM(TotalAmount),
    DENSE_RANK() OVER(ORDER BY SUM(TotalAmount) DESC) AS SpenderRank
    FROM Orders GROUP BY CustomerID;
    ```

**Q65: Find the 2nd most expensive product in every category.**
*   **Solution:**
    ```sql
    WITH RankedProducts AS (
        SELECT CategoryID, ProductName, UnitPrice,
        ROW_NUMBER() OVER(PARTITION BY CategoryID ORDER BY UnitPrice DESC) as rn
        FROM Products
    )
    SELECT CategoryID, ProductName FROM RankedProducts WHERE rn = 2;
    ```

## Section 5: Edge Cases and Data Cleaning (Questions 81-100)

**Q81: Find duplicate emails in the `Customers` table.**
*   **Solution:** `SELECT Email, COUNT(*) FROM Customers GROUP BY Email HAVING COUNT(*) > 1;`

**Q82: Write a query to delete those duplicate emails, keeping only the row with the oldest `SignupDate`.**
*   **Solution (Using CTE):**
    ```sql
    WITH Duplicates AS (
        SELECT CustomerID, ROW_NUMBER() OVER(PARTITION BY Email ORDER BY SignupDate ASC) as rn
        FROM Customers
    )
    DELETE FROM Duplicates WHERE rn > 1;
    ```

**Q83: Update all `NULL` LastNames to say 'Unknown'.**
*   **Solution:** `UPDATE Customers SET LastName = 'Unknown' WHERE LastName IS NULL;`

**Q84: Using a CASE statement, classify orders as 'Micro' (<$10), 'Normal' ($10-$100), and 'Large' (>$100).**
*   **Solution:**
    ```sql
    SELECT OrderID, TotalAmount,
    CASE 
        WHEN TotalAmount < 10 THEN 'Micro'
        WHEN TotalAmount BETWEEN 10 AND 100 THEN 'Normal'
        ELSE 'Large'
    END AS OrderSize
    FROM Orders;
    ```

**Q85: A hacker inserted HTML tags into the `FirstName` column (e.g., `<b>John</b>`). Write a query to find them.**
*   **Solution:** `SELECT CustomerID FROM Customers WHERE FirstName LIKE '%<%>%';`

**Q86: Create a View that hides customer emails and only shows the first letter of their last name for privacy.**
*   **Solution (SQL Server):**
    ```sql
    CREATE VIEW vw_PublicCustomers AS
    SELECT CustomerID, FirstName, LEFT(LastName, 1) + '.' AS LastInitial, Country
    FROM Customers;
    ```

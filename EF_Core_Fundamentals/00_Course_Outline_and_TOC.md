# EF Core Fundamentals Course

**Target Audience:** Beginner to Intermediate C# Developers
**Technology Stack:** .NET 8/9, EF Core 8/9, SQL Server / SQLite
**Goal:** A step-by-step guide to mastering the fundamentals of Entity Framework Core, from initial setup to building a real-world API.

## Course Outline

### Module 1: Introduction to Entity Framework Core
*   **What is an ORM?** Understanding Object-Relational Mapping and why we use it.
*   **EF Core vs. The World:** Comparing EF Core with Dapper and ADO.NET.
*   **Core Concepts:** Understanding the `DbContext`, `DbSet`, and Database Providers.
*   **Hello World with EF Core:** Setting up a simple Console Application.
*   **Connecting to Data:** Configuring SQLite and SQL Server providers.

### Module 2: Building Your First Data Model
*   **Plain Old CLR Objects (POCOs):** Defining your data models in C#.
*   **Conventions:** How EF Core automatically infers Primary Keys, Foreign Keys, and table names.
*   **Data Annotations:** Shaping the database schema using attributes like `[Required]`, `[MaxLength]`, `[Table]`, and `[Column]`.
*   **Fluent API (Basics):** An introduction to configuring models inside `OnModelCreating`.
*   **Database Creation:** `EnsureCreated` vs. true Migrations.

### Module 3: Essential CRUD Operations
*   **Create:** Adding single and multiple records using `Add` and `AddRange`.
*   **Read:** Fetching data using `ToList`, `FirstOrDefault`, `SingleOrDefault`, and `Find`.
*   **Basic LINQ:** Filtering data using the `Where` clause.
*   **Update:** Modifying existing records.
*   **Delete:** Removing records from the database.
*   **The Power of SaveChanges:** Understanding how EF Core commits transactions.

### Module 4: Managing Database Schema with Migrations
*   **Introduction to Migrations:** Why we need source control for our database schema.
*   **The CLI and PMC Tools:** Installing `dotnet-ef` and running commands.
*   **Creating and Applying Migrations:** Using `Add-Migration` and `Update-Database`.
*   **Understanding Migration Files:** Deciphering the `Up` and `Down` methods.
*   **Data Seeding:** Populating the database with initial lookup data.

### Module 5: Modeling Relationships
*   **One-to-Many Relationships:** The most common relationship (e.g., Author and Books).
*   **Navigation Properties:** Working with Reference and Collection properties.
*   **One-to-One Relationships:** Modeling strict 1:1 data (e.g., User and UserProfile).
*   **Many-to-Many Relationships:** How EF Core handles implicit and explicit join tables.
*   **Cascade Deletes:** Understanding what happens to child records when a parent is deleted.

### Module 6: Querying Data and LINQ
*   **LINQ to Entities:** Translating C# expressions to SQL queries.
*   **Eager Loading:** Fetching related data using `Include` and `ThenInclude`.
*   **Explicit Loading & Lazy Loading:** When and why to use them.
*   **Projection:** Using `Select` to map entities to Data Transfer Objects (DTOs) for performance.
*   **Sorting and Paging:** Using `OrderBy`, `Skip`, and `Take`.

### Module 7: The Change Tracker, Concurrency, and Value Conversions
*   **How EF Core Tracks Changes:** An introduction to the Change Tracker and Entity States (`Added`, `Unchanged`, `Modified`, `Deleted`, and `Detached`).
*   **Read-Only Queries:** Using `AsNoTracking` to massively boost read performance.
*   **Handling Concurrency:** Using Concurrency Tokens to prevent data loss.
*   **Value Conversions:** Bridging the gap between C# complex types (Enums, Lists, Value Objects) and SQL columns.

### Module 8: Owned Entities and Complex Types
*   **Owned Entities:** Understanding `OwnsOne` and `OwnsMany` for Domain-Driven Design Value Objects.
*   **Complex Types (EF Core 8+):** How they differ from Owned Entities (no identity, no tracking overhead).
*   **Table Splitting vs Separate Tables:** How EF Core stores these objects in relational databases.

### Module 9: Real-World Application Integration
*   **EF Core in ASP.NET Core:** Registering `DbContext` in the Dependency Injection container.
*   **Repository Pattern vs. Direct DbContext:** Discussing architecture choices.
*   **Logging and Debugging:** Viewing the actual SQL generated by EF Core.

# Mastering Entity Framework Core
### From Fundamentals to Enterprise SaaS Architecture

**Target Audience:** Senior Backend Engineers & Solution Architects
**Technology Stack:** .NET 9+, EF Core 9+, SQL Server, Azure SQL
**Case Study:** Multi-Tenant EV Charging Management Platform

## Book Description
This is not a beginner's tutorial or a documentation summary. This is the definitive engineering manual for Entity Framework Core. It is designed for software engineers who want to transcend basic CRUD operations and master the internal mechanics of EF Core. You will learn the exact T-SQL generated by your LINQ queries, the memory allocation behavior of the Change Tracker, and how to architect high-performance, multi-tenant SaaS applications using Clean Architecture and CQRS.

---

## Table of Contents

### Part I: Core Mechanics and Modeling
**Chapter 1: The Evolution of Data Access and EF Core Fundamentals**
*   The philosophy of ORMs, the history of Entity Framework, and a strict comparative analysis between EF Core, Dapper, and ADO.NET. Introducing the core primitives: `DbContext` and `DbSet`.

**Chapter 2: The DbContext and the Change Tracker**
*   A forensic deep dive into the heart of EF Core. Understanding `DetectChanges`, Entity State Machines, Identity Resolution, and Snapshot Tracking memory overhead.

**Chapter 3: Advanced Entity Modeling and the Fluent API**
*   Transcending Data Annotations. Mastering the `OnModelCreating` pipeline, Value Converters, Shadow Properties, Backing Fields, Keyless Entities, and Entity Splitting.

**Chapter 4: Mastering Relationships and Inheritance**
*   Architecting One-to-Many and Many-to-Many relationships. Deep dive into Owned Types, Table Splitting, and Inheritance patterns (TPH, TPT, TPC) and their impact on execution plans.

### Part II: The Query Pipeline and Performance
**Chapter 5: The Query Pipeline and LINQ Translation**
*   How EF Core translates Expression Trees into Abstract Syntax Trees and finally into T-SQL. Mastering Filtering, Sorting, Projection, `Include`, and the critical debate between Split Queries and Single Queries.

**Chapter 6: High-Performance EF Core**
*   Bending EF Core to achieve microsecond latency. Mastering `AsNoTracking`, Compiled Queries, DbContext Pooling, Bulk Operations (`ExecuteUpdate`/`ExecuteDelete`), and eradicating the N+1 problem.

### Part III: Enterprise State Management
**Chapter 7: Database Migrations and DevOps**
*   Managing schema evolution at an enterprise scale. Creating idempotent migration scripts, handling Custom SQL, Idempotent Seeding, and strategies for Zero-Downtime production deployments.

**Chapter 8: Transactions, Concurrency, and Resilience**
*   The internal mechanics of `SaveChanges`. Explicit Transactions, Isolation Levels, managing Optimistic Concurrency with RowVersion tokens, and designing Polly Retry Strategies for transient cloud faults.

### Part IV: Architecture and SaaS Patterns
**Chapter 9: ASP.NET Core Integration and Clean Architecture**
*   Dependency Injection lifetimes (`Scoped` vs `Transient`). Integrating DbContext into Clean Architecture, the Repository Pattern debate, Unit of Work, and dispatching Domain Events via Interceptors.

**Chapter 10: Enterprise SaaS Architecture**
*   Designing Multi-Tenant systems. Utilizing Global Query Filters, implementing Soft Deletes natively, Audit Logging via DbContext Interceptors, and SQL Server Temporal Tables.

**Chapter 11: Security, Row-Level Security, and Encryption**
*   Defense-in-depth data access. Preventing SQL Injection, securing connection strings, integrating SQL Server Row-Level Security natively with EF Core, and utilizing Always Encrypted.

### Part V: Production Readiness
**Chapter 12: Enterprise Testing Strategies**
*   Why mocking `DbContext` is a severe anti-pattern. The limitations of the SQLite InMemory provider. Architecting flawless Integration Tests using Dockerized Testcontainers and the Transaction Rollback pattern.

**Chapter 13: Azure SQL Deployment and Observability**
*   Deploying to the cloud. Configuring Managed Identities (Passwordless Auth), resilient connections, Distributed Tracing (OpenTelemetry), and the Master EF Core Production Checklist.
